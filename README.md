

# 🌐 English

[Live Demo](https://stan-mqz-festival-musica.netlify.app/)

![image](https://github.com/user-attachments/assets/76a8f259-09c7-4dd2-b108-97f27021d512)


A vibrant and interactive landing page for a music festival, built using HTML, CSS, Sass and JavaScript. This project features various sections containing festival information, a gallery created with JavaScript, and a dynamic navigation menu that highlights the current section.

## Features

* **Festival Information:** Different sections provide details about the festival, including dates, lineup, location, and ticket information.
* **Interactive Gallery:** A JavaScript-powered gallery displays images of past festivals, with each image viewable in a modal.
* **Dynamic Navigation Menu:** The menu highlights the active section in yellow as the user scrolls through the page, enhancing navigation and user experience.

## Technologies Used

* **HTML:** The standard markup language for creating web pages.
* **CSS:** Used for styling the landing page layout and design.
* **Sass:** A preprocessor for CSS that helps organize styles and enhances functionality.
* **JavaScript:** Utilized to create an interactive gallery and dynamic navigation features.

# 🌐 Español

Una página de aterrizaje vibrante e interactiva para un festival de música, construida con HTML, CSS, Sass y JavaScript. Este proyecto incluye varias secciones con información del festival, una galería creada con JavaScript y un menú de navegación dinámico que resalta la sección actual.

## Características

* **Información del Festival:** Diferentes secciones brindan detalles sobre el festival, incluyendo fechas, artistas, ubicación e información sobre boletos.
* **Galería Interactiva:** Una galería impulsada por JavaScript muestra imágenes de festivales anteriores, con la posibilidad de ver cada imagen en un modal.
* **Menú de Navegación Dinámico:** El menú resalta en amarillo la sección activa a medida que el usuario se desplaza por la página, mejorando la navegación y la experiencia del usuario.

## Tecnologías Utilizadas

* **HTML:** El lenguaje de marcado estándar para crear páginas web.
* **CSS:** Usado para dar estilo al diseño y la apariencia de la página.
* **Sass:** Un preprocesador de CSS que ayuda a organizar estilos y mejora la funcionalidad.
* **JavaScript:** Utilizado para crear una galería interactiva y funciones dinámicas en el menú de navegación.
